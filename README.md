# Onirevo

Website institucional da Onirevo, disponível em [onirevo.pt](https://onirevo.pt) e construído a partir do conceito visual aprovado para a marca.

## Estrutura

- `index.html` — landing page institucional
- `styles.css` — design system, layout responsivo e identidade visual

## Visualização local

Abra `index.html` diretamente no navegador ou use um servidor local simples, por exemplo:

```bash
python3 -m http.server 8000
```

Depois aceda a `http://localhost:8000`.

## Publicação rápida

O projeto é estático e pode ser publicado diretamente em GitHub Pages, Vercel, Netlify ou Railway.
